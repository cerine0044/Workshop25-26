# 🎮 Pandora Box - Utilisateur 2

## 🚀 Démarrage Ultra-Rapide

### Option 1 : Script Automatique (Recommandé)
```bash
# Sur macOS/Linux
./installer.sh

# Sur Windows (PowerShell)
.\installer.ps1
```

### Option 2 : Installation Manuelle
```bash
# 1. Installer les dépendances
flutter pub get

# 2. Ouvrir le navigateur à l'adresse fournie par l'utilisateur 1
# Exemple : http://192.168.1.100:8084
```

## 📋 Fichiers Inclus

- `lib/` - Code source de l'application Flutter
- `assets/` - Images et sons du jeu
- `pubspec.yaml` - Configuration des dépendances
- `pubspec.lock` - Versions exactes des packages
- `analysis_options.yaml` - Configuration du linter
- `INSTRUCTIONS_UTILISATEUR2.md` - Guide détaillé
- `installer.sh` - Script d'installation automatique

## 🌐 Connexion au Jeu

1. **Demandez l'IP** du PC principal à l'utilisateur 1
2. **Ouvrez votre navigateur**
3. **Allez à** : `http://[IP]:8084`
4. **Jouez !** 🎉

## 🔧 Prérequis

- **Flutter SDK** 3.6.0 ou plus récent
- **Navigateur web** moderne
- **Connexion WiFi** (même réseau que l'utilisateur 1)

## 📞 Support

En cas de problème, consultez `INSTRUCTIONS_UTILISATEUR2.md` pour le guide complet de dépannage.

# Configuration Firebase pour Multijoueur

## Étapes pour configurer Firebase réel

### 1. Créer un projet Firebase
1. Allez sur [Firebase Console](https://console.firebase.google.com/)
2. Cliquez sur "Créer un projet"
3. Nommez votre projet (ex: "pandora-box-multiplayer")
4. Activez Google Analytics (optionnel)
5. Créez le projet

### 2. Activer Firebase Realtime Database
1. Dans le menu de gauche, cliquez sur "Realtime Database"
2. Cliquez sur "Créer une base de données"
3. Choisissez "Test mode" pour commencer
4. Sélectionnez une région (ex: europe-west1)
5. Confirmez la création

### 3. Configurer les règles de sécurité
Dans l'onglet "Règles" de Realtime Database, remplacez le contenu par :
```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}
```

### 4. Obtenir les clés de configuration
1. Cliquez sur l'icône d'engrenage → "Paramètres du projet"
2. Faites défiler vers le bas jusqu'à "Vos applications"
3. Cliquez sur l'icône web (</>) pour ajouter une application web
4. Nommez l'application (ex: "Pandora Box Web")
5. Copiez les clés de configuration

### 5. Mettre à jour firebase_options.dart

### 6. Redémarrer l'application
```bash
flutter run -d web-server --web-port 8080
```

## Solution Alternative : Serveur Local Partagé

Si vous préférez ne pas utiliser Firebase, vous pouvez utiliser un serveur local partagé :

### 1. Installer Firebase CLI
```bash
npm install -g firebase-tools
```

### 2. Initialiser Firebase Local Emulator
```bash
firebase init emulators
# Sélectionnez Realtime Database
# Choisissez un port (ex: 9000)
```

### 3. Démarrer l'émulateur
```bash
firebase emulators:start --only database
```

### 4. Modifier la configuration
Dans `firebase_options.dart`, changez le `databaseURL` pour :
```dart
databaseURL: 'http://localhost:9000?ns=VOTRE_PROJECT_ID',
```

## Test de Connexion

1. **PC 1** : Ouvrez `http://localhost:8080` et créez une room
2. **PC 2** : Ouvrez `http://IP_DU_PC1:8080` et rejoignez la room
3. Les deux PC devraient maintenant être synchronisés !

## Dépannage

- **Erreur de CORS** : Vérifiez que Firebase est bien configuré
- **Connexion refusée** : Vérifiez que le port 8080 est ouvert
- **Rooms non synchronisées** : Vérifiez les règles de sécurité Firebase
